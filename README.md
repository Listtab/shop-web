# 纯网页版 · 商品展示（网页版分支）

一个**纯网页**的商品展示系统，不依赖微信小程序。整套就两个页面 + 一份数据：

- **对外展示宣传页** `index.html` —— 顾客/客户打开看的（轮播、店铺名片、分类、商品网格、详情、联系）
- **管理页面** `admin.html` —— 你自己改内容用的（店铺信息 / 轮播 / 分类 / 商品，可增删改、上架下架）
- **数据文件** `data.json` —— 上面两个页面共用的全部内容

没有手机外壳，就是普通响应式网页：**手机上满屏、电脑上自动收成一条**，微信里点链接直接能开，各平台浏览器都能跑。

---

## 一、在本地先看看（不用部署）

需要本机装了 Node.js：

```bash
cd web-version
node server.js
```

| 用途 | 地址 |
|------|------|
| 展示页（给顾客看） | http://127.0.0.1:8099/ |
| 后台页（你来管理） | http://127.0.0.1:8099/admin |

端口被占用就换：`PORT=8088 node server.js`

## 二、部署到 Gitee（让所有人都能访问 + 随时改）

### 第 1 步：把三个文件传上 Gitee
在你自己的 Gitee 账号新建一个**公开仓库**，把这三个文件放进去（放在仓库根目录）：
```
index.html      ← 展示页（Gitee Pages 默认入口）
admin.html      ← 管理页
data.json       ← 数据
```
> 直接网页拖拽上传，或 git 推上去都行。`data.json` 是公开可读的，这没问题。

### 第 2 步：开启 Gitee Pages
仓库页面 → **服务** → **Gitee Pages** → 选择分支（建议用 **master**）、部署目录选 **/（根目录）** → 开启。
开启后会得到一个网址，类似：`https://你的用户名.gitee.io/仓库名/`
这就是对外展示页地址，发给客户、发微信都行。

### 第 3 步：怎么管理（改内容）
打开 `admin.html`（可以是 Gitee Pages 上的 `.../admin.html`，也可以就在你电脑本地双击打开）。
- 改店铺信息 / 轮播 / 分类 / 商品
- 底部点 **「保存」**（临时存到本机浏览器）
- 展开「发布到网上」填一次 **码云用户名 / 仓库名 / 私人令牌**（令牌在 gitee.com 个人设置里生成），之后点 **「推送到码云」**
- 管理页会**直接用浏览器把新的 `data.json` 写回你的仓库** → Gitee Pages 重新发布 → 展示页自动更新

> ⚠️ **改完若展示页没立刻变**：去 Gitee Pages 设置点一下「更新」按钮（个别情况 Pages 不会自动重建）。
> ⚠️ 管理页**必须推到和 Gitee Pages 同一个分支**（默认 master），否则展示页读不到新文件。

## 三、管理页的两种模式（自动识别，不用你管）

| 场景 | 模式 | 保存 / 发布怎么走 |
|------|------|------|
| 连着本地服务器（`node server.js`） | 本地服务器模式 | 保存写本地文件；发布走服务器推码云 |
| 直接以静态网页部署（Gitee Pages 等） | **静态模式（直推码云）** | 保存暂存本机；发布由**浏览器直接调码云接口**写回仓库 |

页面右上角会显示当前是哪种模式。两种模式下「推送到码云」都能用——码云接口已确认允许浏览器跨域调用，所以**纯静态托管也能发布**。

## 四、在微信里打开 / 各平台兼容性

- 页面是纯原生 HTML/CSS/JS，**零框架、零依赖**，微信内置浏览器（安卓 X5 / 苹果 WKWebView）和任意现代浏览器都正常
- Gitee Pages 是 **HTTPS**，微信里点链接能直接打开，无需备案、无需小程序
- 数据请求带 `?_t=时间戳` 防缓存，改完内容刷新即见，不会被旧缓存卡住
- 「复制微信号」「拨打电话」都做了微信兼容兜底（`navigator.clipboard` 不可用时自动降级）
- 手机上满屏显示；电脑浏览器里自动收成居中一条（普通网页样子，不是手机壳）

---

## 五、日常改内容流程（最短路径）

1. 打开 `admin.html`
2. 改完点「保存」
3. 展开「发布到网上」→ 点「推送到码云」
4. 让客户刷新展示页（或等 Gitee Pages 自动/手动更新）

## 六、和原小程序版的区别

| | 小程序版 `miniprogram/` | 网页版 `web-version/` |
|---|---|---|
| 顾客端 | 微信里的小程序 | 任意浏览器/微信里打开的**网页** |
| 管理端 | 同一套网页后台 | 同一套网页后台（已支持纯静态部署） |
| 要不要发版 | 要编译、提交审核 | **不用**，网页改完发布即生效 |
| 部署到哪 | 微信平台 | **Gitee Pages 等开源平台**（或本地） |
| 月付 | 无 | 无 |
| 域名/备案 | 需要 request 合法域名 | **不需要**，Gitee 域名长期可用 |

## 七、常见问题

- **展示页是空白？** 必须用 `http://` 地址访问（本地服务器或 Gitee Pages），不能 `file://` 直接双击打开首页（那样拉不到 `data.json`）。断网时会显示内置示例数据，不白屏。
- **改了管理页没生效？** 保存后要点「推送到码云」发布；展示页刷新一下。
- **只部署展示页、不公开管理页？** 可以。把 `index.html`+`data.json` 传 Gitee Pages；`admin.html` 留在你自己电脑本地用（本地打开也能推送到同一个仓库）。
- **数据格式**：`data.json` 是标准 JSON。价格填 `0` = 顾客端显示「面议」；商品取消「上架」勾选 = 顾客端看不见。
