本地改只是改你电脑/浏览器里的文件。要让所有顾客看到，要把 data.json 发到网上。
GitHub Pages / Gitee 码云：免费，本页直接用浏览器把文件推送到你的仓库（接口已确认允许跨域）。
腾讯云 COS：国内最稳、微信秒开；先在下方填好 COS 设置，「推送并发布」会把 data.json 传到 COS，图片「选图上传」也会直接存到 COS。
选好平台、填好对应信息后，点「推送并发布」即可。
选「腾讯云 COS」时填下面四项：建一个「公有读私有写」存储桶，并部署一个签发临时上传地址的云函数（代码我用单独文件给你）。图片「选图上传」和「推送并发布」都会走 COS。
